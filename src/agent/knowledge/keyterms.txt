# Deepgram Nova-3 keyterm prompting (TASK-04).
#
# The cheapest accuracy win available. Without these, English nouns inside an
# Urdu sentence get mangled - and those are exactly the words the intent hangs
# on (a brand name, "order", "prescription").
#
# Two rules learned the hard way:
#   1. Keep the list to 40-60 high-value terms. An over-broad list biases the
#      model toward these words even when they were not said.
#   2. List what callers actually say, not what the brochure calls it.
#
# A pharmacy has more brand names than this list can ever hold, so there are
# two layers and this is only the first. Keyterms cover the drugs callers ask
# for most; everything else is caught downstream by products.search_terms,
# which carries the misspellings a transcript actually produces. Adding the
# whole catalogue here would make recognition worse, not better.
#
# Lines starting with # and blank lines are ignored.
